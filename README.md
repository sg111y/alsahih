# تطبيق الجمع المسند — شجرة الأسانيد (PWA)

## الرفع على GitHub Pages
1. أنشئ حسابًا على github.com ثم اضغط New repository، وسمّه مثلًا `asanid` واجعله Public.
2. اضغط Add file ثم Upload files، واسحب **محتويات** هذا المجلد (وليس المجلد نفسه) بما فيها مجلد `icons` والملف المخفي `.nojekyll`، ثم Commit changes.
3. من Settings ثم Pages: اختر Source = Deploy from a branch، والفرع `main`، والمجلد `/ (root)`، ثم Save.
4. بعد دقيقة يظهر الرابط: `https://USERNAME.github.io/asanid/`

## التثبيت كتطبيق
- أندرويد (Chrome): القائمة ثم «تثبيت التطبيق».
- آيفون (Safari): مشاركة ثم «إضافة إلى الشاشة الرئيسية».
بعد أول فتح يعمل بدون إنترنت.

## بطاقة الباركود
افتح `qr.html` من الموقع (…/qr.html)، الصق الرابط، اضغط «أنشئ البطاقة» ثم نزّل الصورة أو اطبعها.

## عند تعديل الملفات
غيّر رقم النسخة في `sw.js` (`asanid-v1` إلى `asanid-v2`) ليصل التحديث للمستخدمين.

## رسالة لكل المستخدمين
عدّل `announcements.json` (العنوان والنص) وغيّر قيمة `id` لتظهر من جديد لمن أغلقها. اجعل `show` تساوي `false` لإخفائها.
